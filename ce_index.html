Voyager en Bretagne

Les adjectifs démonstratifs : ce · cet · cette · ces  ·  Niveau A1+  ·  Classe 9

📌 Rappel de la règle

ce masculin singulier
→ ce château
cet masc. sing. + voyelle / h muet
→ cet hôtel, cet itinéraire
cette féminin singulier
→ cette plage
ces pluriel (masc. & fém.)
→ ces rochers

Exercice 1 Choisis le bon adjectif démonstratif !

Choisis ce, cet, cette ou ces pour compléter chaque phrase.

1. ___ village breton est très pittoresque.

2. J'adore ___ crêpes bretonnes !

3. ___ église est très ancienne.

4. ___ hôtel est près de la plage.

5. Nous visitons ___ château demain.

6. ___ itinéraire est parfait pour les familles.

7. ___ phare est magnifique au coucher du soleil.

8. ___ rochers sont dangereux pour les bateaux.

          ✏ Exercice 6 Mon journal de voyage en Bretagne

          Écris une entrée de journal de voyage (environ 80–100 mots). Utilise les aides ci-dessous et emploie ce / cet / cette / ces au moins 3 fois !

          🗓 Débuts de phrases

          • Aujourd'hui, je / nous …
          • Le matin, on …
          • D'abord, … ensuite …
          • C'est …
          • J'adore / Je trouve que …
          • Ce soir, …

          🏃 Activités

          • visiter (le château / la ville)
          • manger (des crêpes / une galette)
          • faire du vélo / du surf
          • aller à la plage / au marché
          • prendre des photos
          • se promener dans la forêt
          • voir les menhirs de Carnac

          📖 Vocabulaire utile

          • ce village / ce phare
          • cet hôtel / cet endroit
          • cette plage / cette région
          • ces rochers / ces bateaux
          • magnifique / super / calme
          • historique / ancien(ne)
          • près de la mer / du port
          • avec ma famille / mes amis

          ✅ À vérifier

          • Ce / Cet / Cette / Ces ≥ 3×
          • Verbe conjugué au présent
          • Au moins 4 activités
          • Phrases complètes
          • Majuscule + point

          ⚠ Cette tâche n'est pas limitée dans le temps. Ton professeur corrigera ton texte.

          Liste de contrôle – Journal de voyage

          • 🟢 Démonstratifs : as-tu utilisé ce / cet / cette / ces au moins 3 fois ?
          • 🟢 Verbes : les verbes sont-ils bien conjugués au présent ?
          • 🟢 Activités : as-tu mentionné au moins 4 activités différentes ?
          • 🟢 Vocabulaire : as-tu utilisé des adjectifs (magnifique, historique…) ?
          • 🟢 Longueur : environ 80–100 mots ?
          • 🟢 Ponctuation : majuscules et points corrects ?

          ✨ Exemple de début :
          Aujourd'hui, nous visitons ce château magnifique près de cette plage. Le matin, je fais du vélo avec mes amis. On mange des crêpes dans cet ancien restaurant du port…
